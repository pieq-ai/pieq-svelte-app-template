fix: implement employee document upload storage and preview workflows

This commit fixes the document upload persistence issue in the Employee Document step and introduces a document preview/download workflow.

- **DAO Layer**: Added `findByCuid` in `document.dao.ts` to query specific documents by CUID.
- **Service Layer**: Added `getDocumentByCuid` in `document.service.ts` to fetch binary documents.
- **API Endpoint**: Created `src/routes/api/employees/[cuid]/documents/[docCuid]/+server.ts` to serve stored binary document data as a Response with correct Content-Type and inline Content-Disposition.
- **UI Component**: Updated `StepDocuments.svelte` to read file inputs using `FileReader` as base64 and bind `file` state for previews. Added a preview Eye icon for PDF, image, and downloadable files. Tracked file loading to disable navigation buttons during reads.
- **Testing**: Bootstrapped unit tests in `tests/unit/document.service.test.ts` for getDocumentByCuid and replaceDocuments.
- **Code Graph**: Updated AST knowledge graph using graphify.
